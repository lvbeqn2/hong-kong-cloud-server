## 线路：两套叫法，一条判断标准

香港机房的线路名词有两套常见的说法，理解了就是同一件事。

一套按回程路由分三档。优质 BGP 是电信回程走 CMI、联通回程在 CU/NTT/CMI 之间均衡、移动回程走 Level3，国际方向择优选路，适合国内三网都有访问需求又兼顾海外的场景。精品 BGP 把电信和联通回程都收拢到 CU、移动走 CMI，国内三网都走骨干直连，晚高峰波动小，适合纯国内访问为主、对延迟敏感的业务。国际 BGP 不含 CMI 和 CU，国际方向择优选路，国内方向延迟明显偏高，只适合纯出海业务。

另一套按优化等级分四档。CN2 GIA 全程走 CN2 直连中国电信，有 QoS 高优先级，到大陆主要城市延迟在 10–25ms，繁忙时段也不容易堵。BGP 优化聚合多线，回国延迟 20–40ms，价格便宜不少。国际线路官方会直接提示「中国大陆用户访问延迟将大幅增高」。还有一档 BGP 高防，自带 DDoS 防护，被攻击时自动切到高防线路。

判断规则很简单：

- 用户在大陆 → CN2 GIA 优先，预算紧就精品 BGP
- 用户在海外 → 国际线路，走 CN2 GIA 反而绕路
- 担心被打 → 高防线路，代价是月费上一个大台阶

延迟量级上，优化线路在广东能压到 30ms 以内，全国平均 60–80ms；国际 BGP 因为回程绕路，国内访问能到 150ms 以上。这个差距在网页首屏加载上是能感觉出来的。

## 带宽口径：最容易踩的坑

同样写「200M 带宽」，可能是 200Mbps 不限流量，也可能是 200Mbps 但每月只有 600GB–1500GB 流量，超了限速到 1Mbps。

1Mbps 是什么概念：跑满也就 128KB/s，一个普通网页的图片都加载得吃力。做图床、视频站、下载站这类持续吃出口的业务，选限量套餐等于给自己埋雷。反过来，一个日访问几百人的企业官网，一个月可能用不到 100GB，买不限流量档是白花钱。

下单前问清楚三件事：带宽是 Mbps 还是 MB/s；流量是「不限」还是「每月 N GB 后限速」；限速后的速度是多少。这三条写在同一张表格里的商家不多，通常要翻到产品详情页或 FAQ 才看得到。

## 原生 IP：不是所有「香港 IP」都登记在香港

香港的 IPv4 资源很紧张，不少商家分配的地址是从 APNIC、RIPE、AFRINIC 各区域广播过来的。这些 IP 都宣告到香港，路由上也在香港，但部分第三方服务会按 IP 的注册归属地做判断，比如解锁流媒体、注册某些 AI 服务。

这带来两个反直觉的结论。

第一，贵的不一定给原生 IP。有的商家默认开的是 BGP IP，原生 IP 要单独申请，加价 200 元/月/个，并且官方会明确提示原生 IP 会让大陆访问延迟大幅增高。延迟变高的原因是原生 IP 往往不做回国优化，路由走了更远的路径。

第二，没有明确需求就别开。跑网站、跑 API、跑代理，普通 BGP IP 完全够用。只有当你确实需要某个按 IP 归属判断的服务时，这笔加价才有意义。

## 只写在条款里的限制

这些内容不会出现在宣传页顶部，但会影响你能不能正常用。

- **25 端口（发邮件）要交保证金**。部分商家默认封 25 端口，开通需交 150 元保证金。做邮件服务的要先算进成本。
- **超流量限速到 1Mbps**。流量型套餐超出额度后不是加钱，是直接降速。
- **切换线路要付费**。有的产品线默认给优质 BGP，想切精品 BGP 需另付 50 元服务费。
- **Windows 授权另购**。默认只给 Linux，装 Windows 要单独买授权，并且对配置有下限要求。
- **可用区决定线路**。同一家商家的不同可用区，可选线路不一样，下单时选错区就选不到想要的线路。
- **1 核容易 CPU 100%**。商家自己的下单页会提示「建议至少使用 2 核心」，跑 WordPress、带数据库的小型应用尤其明显。
- **退款有手续费**。3 天退款是行业常见口径，但有的按条款收 10%–30% 手续费，有的第二次退款只能退到账户余额。

## 买前先试：退款期和免费试用怎么用

香港云服务器普遍有 3 天内的退款窗口，这三天不是给你「用三天」的，是用来做验证的：在你自己的网络环境里 Ping 一下，跑一下你的实际业务，看晚高峰掉不掉速。

有的商家还提供免费试用，比如 1 核 2G 配 2M CN2 的机型可试用 7 天、2 核 4G 配 5M CN2 可试用 3 天，前提是没买过也没试用过该商家的产品并完成实名认证。这种试用的价值在于零成本验证线路，比看任何测评都准。

用退款期做测试的话，注意两点：一是在期限内提交工单，不是期限内「决定退」；二是数据提前备份，退款后机器会被回收。

## 按场景选：六种情况六条规则

**个人博客、技术练手、小工具站**：年付轻量档，1 核 1G 或 2 核 2G。一年一百多块，30G 硬盘加几百 GB 月流量，跑 WordPress、Hexo、Telegram bot 够用。

**企业官网、中小型电商**：2 核 4G 配 CN2 GIA 或精品 BGP。1 核在并发上来后会明显吃力，5M 带宽足够中型站点日常。

**图床、云盘、下载站**：大带宽加不限流量。这一档千万别碰限量套餐，超量限速 1Mbps 会让整站不可用。

**AI 应用、API 中转、视频转码**：CPU 和内存比带宽重要，AMD EPYC 平台或高主频机型，内存 8G 起步。

**外贸独立站、跨境电商**：国际线路，不要 CN2 GIA。你的客户在海外，回国优化对他们是绕路。

**有 DDoS 风险的业务**：高防线路。防护能力的价格不便宜，但被攻击几小时停服的损失通常更高。

**日活过万、要独享资源**：这个量级该看独立服务器了。第三方测评在 2026 年 10 月发布时列出的活动价里，入门独服有 300 元/月、450 元/月档，配 10–15Mbps 带宽、2 个 IP、无限流量；20Mbps 起、3 个 IP、带 20G DDoS 防御的机型在 1288 元/月。这些是测评发布时的活动价，当前是否仍有效要以各商家页面为准。独服的价值在资源独占和多 IP，带宽反而不是这个价位的重点。
